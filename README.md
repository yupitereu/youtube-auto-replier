# 유튜브 답글 도우미

현재 읽어온 최상위 댓글 전체를 선택하고, 원댓글 작성자의 이름을 넣은 답글을 **검토 후 순차 게시**하는 크롬 확장 프로그램입니다. 유튜버가 로그인한 크롬에서 직접 실행합니다.

## 0.3.18 동작

- 웹페이지를 덮지 않는 크롬 기본 사이드 패널 (Chrome 116 이상)
- 댓글 읽기 시 전체 선택, 전체 선택·선택 해제·개별 제외
- `{닉네임}` 변수와 대상별 문구 미리보기
- 검토·확인 후 선택한 댓글에 순차 게시, 진행 수·결과 표시
- 작업 중단, 첫 오류·불확실한 게시 결과에서 자동 중단
- 게시 직전 처리 중 기록, 화면에서 새 답글 확인 후 완료 기록
- 새로고침 후 처리 이력 대상 제외 (같은 브라우저 프로필 기준)
- 시작 후 입력 → 게시 버튼 자동 클릭 → 등록 확인까지 자동 진행
- 기존 입력이 확정 문구와 정확히 같으면 이어서 등록, 다른 초안은 덮어쓰지 않음

**전체는 현재 읽어온 댓글을 뜻합니다.** 영상의 미로딩 댓글·스크롤 밖에서 DOM이 제거된 댓글까지 모두 수집하는 기능은 없습니다. 필요한 만큼 직접 댓글을 불러온 뒤 다시 읽고 대상 수를 확인하세요.

## 기술과 구조

| 기술 | 역할 |
| --- | --- |
| Manifest V3 + WXT | 확장 권한·Manifest 생성·개발·빌드 |
| React + TypeScript | 대상 선택·닉네임 변수·검토·실행 UI |
| Chrome Side Panel + 콘텐츠 스크립트 | 브라우저 옆 패널과 유튜브 DOM 작업 분리, Port 통신 |
| chrome.storage.local | 문구와 게시 상태·시각만 로컬 저장 |
| Web Locks | 같은 확장의 여러 사이드 패널에서 동시 게시 실행 방지 |
| Playwright + axe | 실제 확장을 로드한 로컬 브라우저 테스트·접근성 확인 |

별도 서버·로그인 쿠키 보관·YouTube API 키는 사용하지 않습니다. [기술 설명](docs/architecture.md)을 참고하세요.

## 설치·업데이트

```sh
cd /Users/nine/IdeaProjects/youtube-auto-replier
nvm use
pnpm install
pnpm build
```

1. 크롬 주소창에서 `chrome://extensions` → **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램 로드**에서 `.output/chrome-mv3` 폴더를 선택합니다. 숨김 폴더가 안 보이면 ⌘⇧G로 전체 경로를 입력합니다.
3. 기존 설치가 있다면 확장 카드의 **새로고침**을 누릅니다.
4. **유튜브 또는 테스트 탭도 새로고침**합니다. 열려 있던 패널은 이전 코드입니다.
5. 확장 아이콘을 고정하고 대상 영상에서 클릭합니다. 브라우저 옆에 사이드 패널이 열립니다. 페이지 가용 폭은 줄어들지만 콘텐츠를 패널이 덮지 않습니다.
6. 기존 버전에서 업데이트할 때 `sidePanel` 권한 추가로 사용 설정 확인이 나타나면 활성화합니다. 패널 최하단에서 `v0.3.18`을 확인합니다.
7. 닫기는 크롬 사이드 패널 상단의 닫기 버튼을 사용합니다. 다시 열면 댓글을 다시 읽고 검토합니다. 영상 탭 새로고침 후에는 **댓글 읽기**를 누릅니다. 접근 권한이 없으면 해당 영상에서 확장 아이콘을 눌러 다시 엽니다.

```text
/Users/nine/IdeaProjects/youtube-auto-replier/.output/chrome-mv3
```

## 닉네임 사용

```text
{닉네임}님, 기다려주신 공구가 오픈했어요!
아래 영상의 더보기에서 구매 링크를 확인해주세요.
https://youtu.be/...
```

`@하늘` 댓글에는 `하늘님, …`, `@바다` 댓글에는 `바다님, …`로 바뀝니다. 앞의 @만 제거하고 표시된 작성자 이름을 그대로 사용합니다. **실제 @멘션이나 별도의 실명 조회 기능이 아닙니다.** 유튜브에 핸들이 표시돼 있으면 그 핸들이 사용됩니다. `{닉네임}`을 쓰지 않으면 같은 문구가 들어갑니다. 다른 `{변수}`는 오류로 안내합니다.

## 먼저 로컬에서 시험

```sh
pnpm fixture
```

`http://localhost:8765/fixtures/youtube.html`을 엽니다. 로컬 화면의 게시 버튼은 테스트 댓글만 추가하며 유튜브로 전송하지 않습니다.

1. 확장 아이콘 → **댓글 읽기**를 누릅니다. 이력이 없는 대상이 전체 선택됩니다.
2. 정상 테스트 대상인 `@하늘`, `@바다`만 남기고 작성 중·답글 불가 댓글은 제외합니다.
3. `{닉네임}`이 들어간 문구를 입력합니다.
4. **선택한 N개 답글 검토**에서 각 댓글의 이름·문구를 확인합니다. 이때는 게시하지 않습니다.
5. 확인 체크 후 **N개 댓글에 자동 등록 시작**을 누릅니다.
6. 로컬 게시 수와 두 댓글의 서로 다른 이름을 확인합니다.

‘작성 중인 답글’, ‘답글 불가’, ‘댓글 DOM 교체’ 사례에서는 작업이 중단되는 것이 정상입니다. ‘입력만 시험’ 버튼은 제거했습니다. 검토 후 자동 등록 시작을 누르면 댓글마다 직접 게시 버튼을 누르지 않아도 됩니다. 기존 입력 내용이 검토한 문구와 정확히 일치하면 이어서 게시하며, 다른 문구가 있으면 중단합니다.

## 실제 유튜브 사용 경계

- 지원 주소: `https://www.youtube.com/watch?v=...`, `https://www.youtube.com/shorts/...`.
- **답글이 실제로 게시됩니다.** 본인 채널의 허용된 테스트 영상에서 소수 대상으로 먼저 동작을 확인하세요. 이 프로젝트를 만들면서 실제 유튜브에 게시한 적은 없습니다.
- 댓글 창을 열고 직접 스크롤한 뒤 읽습니다. 로딩되지 않은 댓글과 하위 답글은 포함하지 않습니다.
- 현재 로그인한 채널과 공개 문구를 직접 확인합니다. 도구가 채널 소유권을 인증하지는 않습니다.
- 일반 답변이 있어도 새 오픈 답글을 작성할 수 있습니다. 기존 수동 게시를 자동 식별하는 기능은 없습니다. 이미 안내했다면 실행 대상에서 직접 제외하세요.
- 진행 중 오류나 결과 불확실 상태가 생기면 다음 게시를 멈춥니다. 중단 요청 이전에 이미 시도한 게시를 회수하지 않습니다.
- 성공 표시는 **해당 원댓글 아래에서 새로운 동일 본문 답글을 DOM으로 확인했다는 뜻**입니다. 서버 응답·영구 게시·알림 도착을 보장하지 않습니다. 화면 구조가 다르면 실제로 게시됐어도 ‘확인 필요’가 될 수 있습니다.
- 일정 간격은 화면 안정화를 위한 것이며 플랫폼의 게시 제한·스팸 정책을 우회하거나 허용량을 보장하지 않습니다.

## 중복·로컬 이력

문구(`replyDraft`)와 대상 식별키의 게시 상태·시각(`replyHistory`)만 저장합니다. 식별키는 영상과 댓글 ID를 기준으로 만든 해시이며 원문·작성자명·쿠키·비밀번호는 저장하지 않습니다. 댓글 ID를 읽을 수 없으면 작성자 링크와 본문의 지문을 사용합니다. 이 경우 같은 작성자의 동일 문구는 보수적으로 한 대상으로 취급할 수 있습니다.

- `posting`: 게시 시도 직전 기록. 브라우저가 닫혀도 안전하게 자동 재시도하지 않음
- `posted`: 새 답글을 화면에서 확인
- `uncertain`: 게시 시도 결과 불명확. 재게시 대상에서 제외하고 직접 확인

새로고침해도 위 이력이 있는 대상은 자동 선택하지 않습니다. 이력은 **현재 브라우저 프로필 안에서만** 유효합니다. 확장 삭제·저장소 삭제·다른 기기 사용 시 이력은 공유되지 않습니다. 이미 게시한 내용은 프로그램에서 자동 삭제하지 않습니다. 이력 초기화 버튼은 중복 게시를 유발할 수 있어 제공하지 않습니다.

실제 YouTube DOM은 계정·화면 실험에 따라 다르므로 현재 선택자·게시 결과 감지는 실제 화면에서 추가 검증이 필요합니다. 브라우저 종료 후에는 실행을 계속하지 않습니다.

## 권한

`activeTab`(사용자가 실행한 탭), `scripting`(스크립트 주입), `storage`(문구·게시 상태 로컬 저장), `sidePanel`(크롬 옆 패널)을 사용합니다. 상시 사이트 접근·cookies 권한·원격 서버 연결은 없습니다.

## 재게시 허용

해당 댓글에서 **재게시 허용 → 이력 해제하고 다시 선택**을 누르면 다시 답글을 등록할 수 있습니다. 기존 유튜브 답글은 삭제되지 않으며, 같은 대상에 재게시하면 중복 답글이 생길 수 있습니다. 해당 댓글의 로컬 이력만 해제하고 다시 선택합니다. 문구를 검토하고 자동 등록을 시작해야 실제로 게시됩니다. 다른 댓글의 이력은 유지되며, 새로고침 후에도 해제 상태가 유지됩니다.

접히거나 로딩되지 않은 답글과 실제 삭제를 DOM만으로 확실하게 구별할 수 없어 삭제 여부를 자동 판정하지 않습니다. 게시 결과가 불확실했던 댓글도 유튜브에서 직접 확인한 뒤 같은 방식으로 해제할 수 있습니다. 이 기능 자체가 유튜브 답글을 삭제하지는 않습니다. 다른 탭이 게시 중이면 이력 해제를 막습니다.

## 키보드 입력

입력 UI는 크롬 확장 페이지에서 실행되며 유튜브 탭의 DOM에 포함되지 않습니다. 따라서 Space·f 키 입력이 유튜브 플레이어 단축키로 전달되지 않습니다. 유튜브 탭 밖으로 입력 이벤트를 막는 전역 리스너는 사용하지 않습니다.

## 사이드 패널과 영상 연결

아이콘 클릭은 `action.onClicked`에서 영상 탭의 activeTab 권한을 확보하고, 비동기 작업을 기다리지 않은 채 `sidePanel.open`을 즉시 호출합니다. 댓글 읽기를 누르면 패널이 현재 활성 영상 탭을 확인하고 스크립트를 주입해 댓글을 불러옵니다. 탭이 바뀌면 기존 연결과 검토를 중단하며, 다른 영상으로 게시 요청을 자동 전환하지 않습니다. 패널과 콘텐츠 스크립트는 확장 Port로 통신합니다. DOM 요소는 영상 탭에만 두고, 화면에는 현재 스캔에 한정된 토큰과 표시용 정보를 전달합니다. 댓글 원문은 저장하지 않습니다. 패널 종료·영상 새로고침으로 연결이 끊기면 진행 중 작업을 중단하고 클릭 후 결과가 불명확하면 재게시에서 제외합니다. 다시 연결해도 이전 선택과 검토는 재사용하지 않습니다.

[Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)를 사용합니다. 사이드 패널은 브라우저 UI가 관리하며 위치·너비는 크롬 설정과 패널 경계 드래그로 조정합니다.

## 아이콘을 눌러도 아무것도 뜨지 않을 때

1. `chrome://extensions`의 도우미 카드에서 새로고침합니다. 웹페이지 새로고침만으로는 Manifest·권한·백그라운드가 업데이트되지 않습니다.
2. **세부정보 → 버전**이 `0.3.18`인지 확인합니다. `0.1.0`이면 초기 백그라운드가 새 콘텐츠 파일을 호출해 패널이 나타나지 않는 조합이 될 수 있습니다.
3. 유튜브 탭도 새로고침한 뒤 아이콘을 누릅니다. 새로 추가된 `sidePanel` 권한 때문에 꺼져 있으면 활성화합니다.
4. 패널은 열리는데 영상 연결 오류가 보이면 **댓글 읽기**를 다시 누릅니다.

0.3.0의 `await setOptions()` 뒤 `open()` 호출은 사용자 클릭 문맥을 잃어 거부될 수 있어 제거했습니다. 0.3.1의 기본 사이드 패널 열기만으로는 실환경에서 activeTab 접근이 연결되지 않아, 0.3.2에서 action.onClicked 처리로 변경했습니다. open 전에 기다리는 작업은 없습니다. 영상 주소를 읽을 권한이 없는 상태도 지원하지 않는 주소와 별도로 안내합니다.

## 이모지가 있는 답글의 완료 확인

0.3.3은 유튜브가 `🎉` 등의 이모지를 이미지로 표시하는 경우에도 `img.alt`를 포함해 본문을 비교합니다. 공백·줄바꿈과 이모지 표시 선택자의 표현 차이를 정규화하되, 서로 다른 이모지를 같은 본문으로 취급하지 않습니다. 이미 등록된 답글을 확인하지 못해 첫 대상에서 중단하던 문제를 수정했습니다. 펼쳐진 답글의 중첩 thread는 원댓글 수집 대상에서 제외합니다.

이전 실행에서 ‘확인 필요’로 남은 이력은 자동으로 지우지 않습니다. 해당 답글은 이미 게시됐을 수 있으므로 같은 대상에 재게시하기 전에 실제 내용을 확인합니다. 이 수정은 기존 답글 삭제나 자동 재발송을 수행하지 않습니다.

## 댓글 읽기 한 번으로 시작

별도 다시 연결·연결 재시도 버튼 없이 **댓글 읽기**가 영상 연결·재연결·댓글 수집을 함께 수행합니다. 영상 새로고침 후에도 같은 버튼으로 다시 읽습니다. 입력 중인 답글 문구는 유지하고, 이전 대상·선택·검토는 새 목록으로 초기화합니다. 읽는 중과 게시 중에는 중복 읽기를 막습니다.

쇼츠 댓글 창이 닫혀 있으면 화면에 보이는 해당 영상의 댓글 버튼으로 먼저 열고, 댓글이 로딩된 뒤 수집합니다. 이미 열린 창은 닫지 않습니다. 댓글을 열 수 없는 경우 이유를 표시하며, 권한이 필요하면 영상 탭에서 확장 아이콘을 누른 뒤 댓글 읽기를 다시 실행합니다. 전체 댓글을 자동 스크롤하는 기능은 아닙니다.

## 답글 내용 입력

댓글 읽기는 제목 영역 오른쪽에 있습니다. 첫 단계에서 댓글을 선택하고, 두 번째 단계에서 답글 내용을 입력합니다. **닉네임 추가**를 누르면 커서 위치에 `{닉네임}`을 넣고 바로 이어서 입력할 수 있습니다. 글자를 선택했다면 그 부분을 대체합니다. `{닉네임}` 자리에 원댓글 작성자의 닉네임이 들어갑니다.

## 등록 중 안내

등록을 시작하면 상단에 **답글 등록이 끝날 때까지 유튜브 댓글 창과 확장 프로그램을 닫지 마세요** 안내를 표시합니다. 스크롤해도 보이며 완료·중단 후 사라집니다. 완료까지 영상과 도우미를 열어둡니다. 쇼츠 댓글 창을 닫으면 남은 등록을 중단하고 이유를 표시합니다. 게시 시도 뒤 창을 닫아 결과를 확인할 수 없으면 확인 필요로 남깁니다.

## 로고

빨간색 말풍선에 재생 표시와 답글 화살표를 조합한 로고를 사용합니다. 원본은 `public/logo.svg`, 크롬용 PNG는 `public/icon/16.png`·`32.png`·`48.png`·`128.png`입니다. 미리보기용 `512.png`도 제공합니다. 툴바·확장 관리·사이드 패널 아이콘과 패널 제목에 적용합니다.
